Style guide / Elementor

Animacje przycisków

Pięć hoverów spójnych z identyfikacją GFT. Wszystko czysty CSS na pseudo-elementach — bez dodatkowego HTML, więc każdy wariant wkleisz w Elementorze przez Advanced → Custom CSS (Pro). Przycisk „Podgląd hover" wymusza stan bez najeżdżania myszką.

01 / Sweep

Wypełnienie od lewej

Główne CTA. Obrys coyote, po najechaniu tło „wjeżdża" od lewej, tekst zmienia kolor na grafit. Ścięte narożniki nawiązują do oktagonu.

Zobacz produkty 
selector .elementor-button {
  position: relative; overflow: hidden;
  background: transparent;
  border: 1px solid #c0aa9a; color: #c0aa9a;
  clip-path: polygon(10px 0, calc(100% - 10px) 0, 100% 10px,
    100% calc(100% - 10px), calc(100% - 10px) 100%, 10px 100%,
    0 calc(100% - 10px), 0 10px);
  transition: color .25s ease;
}
selector .elementor-button::before {
  content: ""; position: absolute; inset: 0;
  background: #c0aa9a;
  transform: scaleX(0); transform-origin: left center;
  transition: transform .32s cubic-bezier(.4,0,.2,1);
}
selector .elementor-button-content-wrapper {
  position: relative; z-index: 1;
}
selector .elementor-button:hover { color: #17130f; }
selector .elementor-button:hover::before { transform: scaleX(1); }
selector .elementor-button:active { transform: translateY(1px); }

02 / Narożniki

Obrys rysowany z narożników

Przycisk drugorzędny. Dwa techniczne narożniki (jak znaczniki celownicze) rozrastają się w pełną ramkę. Dyskretny, bardzo „instruktorski".

Poznaj Octamolle 
selector .elementor-button {
  position: relative;
  background: rgba(103,101,104,.1); color: #ece8e4;
  transition: background-color .25s ease, color .25s ease;
}
selector .elementor-button::before,
selector .elementor-button::after {
  content: ""; position: absolute;
  width: 14px; height: 14px;
  border: 1.5px solid #c0aa9a; pointer-events: none;
  transition: width .3s cubic-bezier(.4,0,.2,1),
              height .3s cubic-bezier(.4,0,.2,1);
}
selector .elementor-button::before {
  top: -1px; left: -1px;
  border-right: none; border-bottom: none;
}
selector .elementor-button::after {
  bottom: -1px; right: -1px;
  border-left: none; border-top: none;
}
selector .elementor-button:hover {
  background: rgba(192,170,154,.08); color: #d8c3b2;
}
selector .elementor-button:hover::before,
selector .elementor-button:hover::after {
  width: calc(100% + 2px); height: calc(100% + 2px);
}

03 / Strzałka

Strzałka + rozstrzelenie liter

Wariant pełny (solid coyote). Na hover ikona odjeżdża w prawo, a litery lekko się rozsuwają — subtelny ruch „do przodu". W Elementorze dodaj ikonę strzałki po prawej stronie tekstu.

Dodaj do koszyka→ 
selector .elementor-button {
  background: #c0aa9a; color: #17130f;
  clip-path: polygon(10px 0, calc(100% - 10px) 0, 100% 10px,
    100% calc(100% - 10px), calc(100% - 10px) 100%, 10px 100%,
    0 calc(100% - 10px), 0 10px);
  transition: background-color .25s ease, letter-spacing .25s ease;
}
selector .elementor-button-icon {
  transition: transform .28s cubic-bezier(.4,0,.2,1);
}
selector .elementor-button:hover {
  background: #d8c3b2; letter-spacing: .2em;
}
selector .elementor-button:hover .elementor-button-icon {
  transform: translateX(6px);
}
selector .elementor-button:active { transform: translateY(1px); }

04 / Znacznik

Oktagon, który się domyka

Najbardziej brandowy wariant: mały konturowy oktagon przed tekstem obraca się o 112,5° i wypełnia kolorem — jak wskaźnik „system uzbrojony". Dobry do CTA sekcji Octamolle.

Jak działa system 
selector .elementor-button {
  position: relative;
  border: 1px solid rgba(103,101,104,.38);
  background: transparent; color: #ece8e4;
  transition: border-color .25s ease, color .25s ease;
}
selector .elementor-button-content-wrapper::before {
  content: ""; display: inline-block;
  width: 9px; height: 9px; margin-right: 10px;
  border: 1.5px solid #c0aa9a;
  clip-path: polygon(30% 0, 70% 0, 100% 30%, 100% 70%,
    70% 100%, 30% 100%, 0 70%, 0 30%);
  transition: transform .35s cubic-bezier(.4,0,.2,1),
              background-color .25s ease;
}
selector .elementor-button:hover {
  border-color: #c0aa9a; color: #d8c3b2;
}
selector .elementor-button:hover
  .elementor-button-content-wrapper::before {
  transform: rotate(112.5deg); background: #c0aa9a;
}

05 / Skan

Linia skanująca (tekstowy)

Do linków „trzeciego rzędu" (menu, karty produktów, „Zobacz więcej"). Cienka linia coyote rośnie od środka pod tekstem.

Przeglądaj ładownice 
selector .elementor-button {
  position: relative;
  background: none; border: none; color: #a29da0;
  transition: color .25s ease;
}
selector .elementor-button::after {
  content: ""; position: absolute;
  left: 50%; bottom: 6px;
  width: 0; height: 1px; background: #c0aa9a;
  transform: translateX(-50%);
  transition: width .3s cubic-bezier(.4,0,.2,1);
}
selector .elementor-button:hover { color: #c0aa9a; }
selector .elementor-button:hover::after { width: 100%; }

Jak wkleić w Elementorze

Elementor Pro
Zaznacz widżet Przycisk → Advanced → Custom CSS → wklej snippet bez zmian. Słowo selector Elementor sam podmienia na klasę tego konkretnego widżetu.
Elementor Free
Nadaj przyciskowi klasę w Advanced → CSS Classes (np. gft-sweep), a snippet wklej w Wygląd → Dostosuj → Dodatkowy CSS, zamieniając każde selector na .gft-sweep .elementor-button.
Typografia przycisku
Ustaw w panelu Elementora: font IBM Plex Mono, wielkie litery, letter-spacing ~1.5–2 px, padding ~16/28 px — wtedy wygląd zejdzie się 1:1 z tą stroną.
Reduced motion
Dla dostępności dołóż raz, globalnie: @media (prefers-reduced-motion: reduce) { .elementor-button, .elementor-button::before, .elementor-button::after { transition: none !important; } }
